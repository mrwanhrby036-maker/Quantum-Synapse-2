# إشارة — نسخة جاهزة لـ GitHub Pages

الموقع مكتوب بـ HTML وCSS وJavaScript فقط. الملفات منفصلة وموجودة جنب بعض مباشرة، بدون مجلدات داخلية وبدون ملف HTML مجمّع أو خطوة build.

## ترتيب الملفات

```text
index.html
style.css
app.js
README.md
.nojekyll
```

- **index.html**: صفحة الموقع. اسمها يجب أن يظل `index.html` بالأحرف الصغيرة.
- **style.css**: تنسيق الموقع بالكامل.
- **app.js**: كود JavaScript بالكامل، مقسّم بعناوين وتعليقات ومنسّق على أسطر واضحة.
- **README.md**: هذا الشرح؛ ليس مطلوبًا لتشغيل الكاميرا.
- **.nojekyll**: ملف فارغ لعرض المشروع كملفات ثابتة على GitHub Pages.

يربط HTML الملفين الآخرين بمسارات نسبية:

```html
<link rel="stylesheet" href="style.css" />
<script type="module" src="app.js"></script>
```

## الرفع والتشغيل

1. فك ضغط الملف ZIP على جهازك. **لا ترفع ZIP نفسه إلى المستودع.**
2. أنشئ مستودعًا على GitHub. استخدام مستودع Public هو الاختيار المعتاد المتاح مع GitHub Free.
3. من **Add file → Upload files** ارفع الملفات المفكوكة نفسها إلى جذر المستودع، بحيث يظهر `index.html` بجوار `app.js` و`style.css` في أول صفحة للمستودع، وليس داخل مجلد إضافي.
4. اضغط **Commit changes**.
5. افتح **Settings → Pages**.
6. عند **Source** اختر **Deploy from a branch**.
7. اختر الفرع الذي رفعت عليه الملفات، وغالبًا اسمه **main**، ثم المجلد **/ (root)**، واضغط **Save**.
8. انتظر اكتمال نشر Pages. ستجد رابط الموقع في صفحة Pages. لمستودع مشروع عادي يكون على النمط:

```text
https://USERNAME.github.io/REPOSITORY/
```

هذا نمط توضيحي؛ استبدل اسم المستخدم والمستودع باسم حسابك ومشروعك، أو استخدم الرابط الذي يعرضه GitHub مباشرة.

9. افتح **رابط الموقع المنشور** على الموبايل، وليس رابط عرض كود `index.html` داخل GitHub.
10. اضغط «السماح وتشغيل الكاميرا» ثم اسمح من المتصفح. إذا سبق رفض الإذن، غيّره من إعدادات الموقع.

لا تحتاج npm أو Node.js أو Python أو GitHub Actions مخصصًا لتشغيل هذه النسخة. ولا تحتاج نسخ الكود إلى ملف واحد.

> GitHub Pages يدعم المجلدات أيضًا؛ ترتيب هذه النسخة مسطّح للتسهيل، وليس شرطًا عامًا للخدمة.

## المزايا

- تتبّع يدين معًا ورسم كل يد بلون مختلف، مع عدّ الأصابع وقراءة كل يد.
- لمسة السبابة للإبهام في أي يد تخفي صورة الكاميرا وتترك رسم نقاط اليدين.
- افصل الإصبعين بوضوح، ثم المس مرة أخرى لإظهار الفيديو.
- تثبيت اللمسة لا يكرر التبديل. لو اليدان مضمومتان معًا، افصل الإصبعين في اليدين قبل اللمسة الجديدة.
- زر «إظهار الفيديو يدويًا» عند تعذّر التقاط اللمسة.
- وضع محاكاة واضح التسمية لتجربة رسم اليدين من غير كاميرا. لا يوجد فيه فيديو حقيقي لإخفائه.

## الكاميرا والخصوصية

- تشغيل الكاميرا يحتاج HTTPS ومتصفحًا حديثًا وإذن المستخدم. GitHub Pages يوفّر رابط HTTPS للموقع المنشور.
- لا يمكن معاينة الكاميرا من صفحة كود GitHub أو من معاينة ملف مقيدة داخل منصة أخرى. افتح الموقع المنشور مباشرة في Chrome أو Safari.
- الصورة الحقيقية تظهر فور منح الإذن، قبل اكتمال تحميل نموذج التتبّع.
- الإخفاء يعني إخفاء **الفيديو كله** وليس إزالة الشخص من الخلفية. الكاميرا والتتبّع يظلان شغّالين محليًا لاكتشاف اللمسة التالية. زر «إيقاف الكاميرا» يوقف الكاميرا فعلًا.
- لا يسجل كود الموقع الفيديو ولا يرفع الصور إلى سيرفر.
- يحتاج الإنترنت لتحميل MediaPipe وWASM من jsDelivr، ونموذج اليد من Google Storage، والخط من Google Fonts. هذه الخدمات تتلقى بيانات الاتصال المعتادة، وليس فيديو الكاميرا.
- التعرف على اللمسة تقدير هندسي؛ دقته تتأثر بالإضاءة وزاوية اليد والتداخل وسرعة الجهاز. اختبره بيدين حقيقيتين على الموبايل المستهدف.
